# 练习架构（出题与掌握机制）

> 本文档说明「翻牌背题」v1.1.0 改造后的核心出题与掌握架构，涵盖每日计划、
> 艾宾浩斯复习调度、连续答对 3 次才掌握的错误重复机制，以及错题本与数据导出。

---

## 1. 总体概览

改造后移除了原来的「顺序 / 随机」练习模式，仅保留两种练习入口：

| 入口 | 模式 (`StudyMode`) | 说明 |
| --- | --- | --- |
| 牌库 → 数据包详情 → 开始每日练习 | `plan` | 按用户设定的每日计划智能出题 |
| 底部导航「错题」页 → 某包练习 | `mistake` | 只练当前标记为「没记住」的卡片 |

**核心目标**：用最少每日题量，按遗忘规律安排复习，保证每张卡片真正掌握。

---

## 2. 数据模型（单卡 `CardRow`）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `status` | `'new' \| 'known' \| 'mistake'` | 掌握状态：未练 / 已掌握 / 没记住 |
| `streak` | `number` | 连续答对次数（达到 `KNOWN_STREAK=3` 才标记 `known`） |
| `box` | `number` | 艾宾浩斯记忆层级（0–8），决定下次复习间隔 |
| `dueAt` | `number` | 下次应复习的时间戳（`<= now` 即到期） |
| `interval` | `number` | 当前复习间隔（天） |
| `reviewed / correct / missed` | `number` | 累计 复习 / 正确 / 错误 次数 |
| `lastSeenAt` | `number?` | 上次作答时间（用于「最近两日易错」判断） |
| `order` | `number` | 在数据包中的原始顺序（新题按序取出） |

每日计划存于 `PackageRow.plan = { old: number, new: number }`，首次练习前由用户设置。

---

## 3. 每日练习出题架构（`buildDailyPlan`）

当用户在数据包详情点「开始每日练习」时，若尚未设置计划则先弹出计划设置
（从预设列表选择「每日 X 旧题 + Y 新题」），随后按以下顺序构建当天队列：

```
buildDailyPlan(packageId, plan):
  1. 最近两日易错（优先）
     recent = 卡片中 status≠known 且 lastSeenAt 在 2 天内 且 missed>0
              按 lastSeenAt 倒序
  2. 艾宾浩斯到期
     due   = 卡片中 status≠known 且 status≠new 且 dueAt <= now
  3. 合并去重：recent 优先，再补充 due → oldPool
     old   = oldPool.slice(0, plan.old)            # 旧题上限
  4. 新题（按数据包顺序）
     fresh = 卡片中 status==='new' 按 order 取前 plan.new 张
  5. 合并并整体随机打乱 → 返回队列
```

**优先级语义**：旧题中先安排「最近两日易错」的题目（刚踩过的坑先补），
再用「艾宾浩斯遗忘曲线」补入已到期（该复习却还没复习）的卡片；
新题每天少量递增；最后整组随机打乱，避免顺序带来的位置记忆。

> 当某类题目不足（如可选旧题少于 `plan.old`）时，按实际可用数量出题，不强行补齐。

---

## 4. 艾宾浩斯复习调度

记忆层级 `box` 与复习间隔（`EB_INTERVALS`，单位：天）：

```
box :  0   1   2   3   4   5   6   7   8
天数:  1   2   4   7  15  30  60 120 240
```

- 卡片「答对并达到 3 连对」→ 标记 `known`，`box+1`，`dueAt = now + EB_INTERVALS[box]` 天。
- 卡片「答错」→ `box` 归零、`dueAt = now`（立即到期，稍后重练）。
- 新卡片 `dueAt = 0`，永远处于「到期」状态，可被每日计划当作新题取出。

该间隔随层级指数增长，对应遗忘曲线对抗节奏：越久没忘，下次间隔越长。

---

## 5. 错误重复机制（连续 3 次正确才掌握）

核心规则（`applyOutcome`）：

- **「知道」**：`correct+1`、`streak+1`。
  - 若 `streak >= 3` → 标记 `known`，按 §4 推进 `box` 与 `dueAt`；
  - 若 `streak < 3` → **保留原有状态不变**（原为 `mistake` 仍保持 `mistake`，
    原为 `new` 仍保持 `new`），不降级、不提前掌握。
- **「不清楚」**：`missed+1`、`streak` 清零、标记 `mistake`、`box` 归零、`dueAt = now`。

**练习中的复现逻辑（`Study.next`）—— 在当前练习内「增加出现次数」**：

- 答完一张卡后**同步**更新队列（不再异步回写，避免顶部「总题数 / 剩余题数」闪烁跳动）；
- 统一规则：只要该卡**尚未达到 3 连对**（本次「知道」后 `streak+1 < KNOWN_STREAK`），
  就统计剩余队列（`queue` + `pending`）中该卡**已有的份数**，**补足到 3 份**：
  · 后面没有相同题目 → 随机创建 3 份插入 `pending`；
  · 已有但题目数不足 3 → 补到 3 份；
  · 已达 3 份 → 不再新增（上限封顶，避免无限膨胀）；
- 因此一张卡会在当前练习中反复出现，直到「连续答对 3 次」才标记 `known` 并退出本轮；
- **这正是需求中的「重复三次 = 在当前练习里增加三次出现」**：答错随机复现并补足 3 份；
  答对但未满 3 次也补足 3 份以便继续累计；任意一次答错则连对计数清零，需重新累计 3 次。

**练习顶部统计**：
- 「已做 X / 总」与进度条 = 完成进度（`answered / (answered + 剩余)`）；
- 右侧圆环 = **掌握率**（`正确数 / 已做数`）：点击「不清楚」时分子（正确数）不变、分母（已做数）变大，
  故掌握率下降；点击「知道」则上升。

---

## 6. 错题本（独立导航页）

- 底部导航新增「错题」页，聚合所有 `status==='mistake'` 的卡片，按数据包分组展示；
- 每组显示错题数量与「练习」按钮，点击进入 `mistake` 模式集中攻克；
- 卡片上标注「连对 x/3」，提示距离掌握还差几次。

---

## 7. 断点续练

未完成一轮退出时，进度（`queue` / `pending` / `answered` / `mode`）写入 `PackageRow`；
再次进入同一包同模式时自动恢复，并显示「已从上次进度继续」提示。
一轮完成后清除进度，下次重新按当日计划出题。

---

## 8. 数据导出 / 导入（含学习进度）

- **导出**：通过 Capacitor `Filesystem` 写入手机「下载」目录（Web 端回退为浏览器下载）。
  导出内容在原始数据包基础上扩展：
  - 每张卡片附带 `progress`（status / streak / box / missed / correct / reviewed /
    lastSeenAt / dueAt / interval）；
  - 数据包顶层附带 `plan`（每日旧题 + 新题）。
- **导入**：兼容新旧两种格式。含 `progress` 则恢复学习进度，含 `plan` 则恢复计划；
  旧格式（无进度/计划）按全新卡片导入。

```jsonc
{
  "title": "数据包名",
  "time": "导入时间",
  "plan": { "old": 10, "new": 10 },        // 新增：每日计划
  "data": [
    {
      "id": 1,
      "type": "问答",
      "question": "…",
      "answer": "…",
      "progress": {                          // 新增：单卡学习进度
        "status": "known",
        "streak": 3,
        "box": 2,
        "missed": 1,
        "correct": 5,
        "reviewed": 6,
        "lastSeenAt": 1700000000000,
        "dueAt": 1700160000000,
        "interval": 4
      }
    }
  ],
  "exportedAt": 1700000000000
}
```

## 9. 出题流程图

```
                 ┌─────────────────────────────┐
                 │  进入数据包 → 开始每日练习    │
                 └──────────────┬──────────────┘
                                │
                   无计划？ ── 是 ──▶ 设置 plan {old, new}
                                │ 否
                                ▼
        ┌────────────────── 构建每日队列 ──────────────────┐
        │ 1) 最近两日易错（lastSeenAt≤2天 & missed>0）      │
        │ 2) 艾宾浩斯到期（status≠known & dueAt≤now）       │
        │ 3) 新题（status==='new'，按 order）              │
        │ 合并 → 取 old 道旧题 + new 道新题 → 随机打乱      │
        └──────────────────────┬──────────────────────────┘
                                ▼
                    逐张翻牌作答（知道 / 不清楚）
                                │
            ┌───────────────────┴───────────────────┐
            │ 不清楚                                  │ 知道
            ▼                                         ▼
    streak=0, 标记 mistake,                streak+1
    box=0, dueAt=now,                      达到3？── 否 ──▶ 继续（plan 模式排到到期日）
    随机插入 pending 稍后复现                │ 是
                                             ▼
                                    标记 known，box+1，
                                    dueAt = now + 间隔(box)
                                │
                                ▼
                    本轮 queue+pending 清空 → 完成小结
```
